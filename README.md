# multigrain-navigator

travelers guide for navigating particle storms: a one-page reference for the intellijel multigrain (manual v1.4.8). every button combo, page, setting and LED colour, with diagrams.

live page: https://mellotom.github.io/multigrain-navigator/
part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

compiled from the intellijel multigrain manual v1.4.8 (2026.10.07). not affiliated with intellijel.

two pages: index.html (the surface) and sheet-2.html (the deep end: sound options, system settings incl. grain size scaling, a/b outs, sampling settings, trim, looping recorder, card and files, boot and rescue, easy-to-forget). the pdf has both pages.
