easy to forget

27

system settings

mgr_27 · alt › hold project 4 s
alt›[ project ] 4 s
open · [ exit ] = back home · global, not per preset
[ rate–size ]
grain size scaling · fig.04 · dim = off (default)
[ size ]
4 s fixed · ≤ 4 s or sample (default) · ≤ 8 s · whole sample
[ rand ]
unipolar 0–5 v (default) · blinking yellow/purple = bipolar
[ latch ]
next jack becomes a scan reset (dim = next)
[ x ] [ /project ]
auto-collect samples on preset save
[ clear ]
30 s idle → back home (on by default)
[ thru ]
knob catch (pass-thru) · dim = jump (default)
[ start ]
gate delay, up to +10 ms, for slow cv
[ wrap ]
select range: 5 v (cw) down to 0.667 v = 8 semitones from 0 v
[ pitch ] [ size–pitch ]
a / b pitch-out scale 1.0–1.1× · test octaves 0 / 1 / 2

30

sampling settings

mgr_30 · alt › sample
alt›[ sample ]
settings only, playback keeps going (sample blinks blue) · or [ alt ]+[ sample ]
[ gain ]
0.5–8.5× · red LED = 1× · line level wants a boost first
[ thrsh ]
separate for each recorder · ccw = off
›sample rec
rec waits for sound · knob LED blue, red when crossed
›looping
auto-freeze after 1 s of quiet · cyan, magenta when crossed
[ resamp ]
dim = ins · lit = resample the outs · looping recorder
[ size ]
looping memory 8 / 16 / 24 / 32 s
[ norm ]
normalize on save, up to +20 dB · can’t be undone

33

card · files

mgr_33 · where people trip
format
.wav · 48 kHz · 16-bit · stereo · ≤ 32 s
won’t work
mono, 24-bit, 96 kHz · 44.1 kHz plays at the wrong pitch · past 32 s is cut off
folders
/Multigrain/Project01–48 · /Wavs (every project) · /Recs · no subfolders
room
128 per project · 128 in /wavs · 1024 recordings
backup
copy the whole /Multigrain folder
card pulled
keeps playing, can’t save · reseat, then reboot
no card
ephemeral: 8 samples in ram, gone at power off
